FluxDM — Linux APT Repository

Privacy-first IDM & universal video/audio downloader for Linux & Windows.

One-Line Install (Ubuntu / Debian / Linux Mint)

curl -fsSL https://aisdevlab.github.io/FluxDM-releases/install.sh | sudo bash

Manual APT Setup

curl -fsSL https://aisdevlab.github.io/FluxDM-releases/fluxdm.gpg | sudo gpg --dearmor -o /usr/share/keyrings/fluxdm.gpg
echo "deb [signed-by=/usr/share/keyrings/fluxdm.gpg] https://aisdevlab.github.io/FluxDM-releases ./" | sudo tee /etc/apt/sources.list.d/fluxdm.list
sudo apt update && sudo apt install flux-dm

Or download directly from GitHub Releases.
